Emotion Detection Web Application

This project is an AI-powered Emotion Detection Web Application developed using Python, Flask, and IBM Watson NLP. The application analyzes customer feedback provided as text and identifies the emotions expressed in the text.

The system detects the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

Features

- Emotion analysis using Watson NLP
- Detection of five core emotions
- Identification of dominant emotion
- Flask-based web interface
- Error handling for invalid input
- Unit testing support
- Static code analysis using Pylint
